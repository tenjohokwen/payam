**Important Envers note:** Envers writes audit rows on transaction commit. Since `TenantService` is `@Transactional` and the test methods call service methods directly, Envers should write audit rows when the transaction commits. However, if the test method itself runs inside a test transaction that rolls back, Envers will NOT write. The test must NOT be annotated with `@Transactional` (the class-level `@SpringBootTest` default is non-transactional, which is correct). Each service call commits its own transaction, and the `jdbcTemplate` queries in the test can read the committed rows.
