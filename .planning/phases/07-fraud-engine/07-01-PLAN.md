**VelocityCheckService.java** — `@Service`. Constructor injects `LettuceConnectionFactory lettuceConnectionFactory` and `FraudRuleCache fraudRuleCache`.

In `@PostConstruct init()`, extract `StatefulRedisConnection<byte[], byte[]>` from the `LettuceConnectionFactory`:
```java
LettuceClientConfiguration clientConfig = lettuceConnectionFactory.getClientConfiguration();
// Use cast: ((LettuceConnectionFactory) lettuceConnectionFactory).getNativeClient()
// actually use: lettuceConnectionFactory.getRequiredNativeClient() — returns RedisClient
RedisClient redisClient = (RedisClient) lettuceConnectionFactory.getNativeClient();
StatefulRedisConnection<byte[], byte[]> redisConnection = redisClient.connect(ByteArrayCodec.INSTANCE);
this.proxyManager = LettuceBasedProxyManager.builderFor(redisConnection).build();
```
Store `ProxyManager<byte[]> proxyManager` as instance field.

IMPORTANT (Pitfall 1): If `LettuceConnectionFactory.getNativeClient()` is not available or returns null (cluster/sentinel mode), fall back to creating a new `RedisClient` from `lettuceConnectionFactory.getHostName()` + `getPort()`. Try the direct cast first; if it throws ClassCastException, use the fallback. Add a `@Slf4j` log warning if fallback is used.

Public method `boolean checkVelocity(FraudSignal signal, String identifier)`:
1. Look up the FraudRule for signal.getSignalName() from `fraudRuleCache.findBySignalName(...)`. If not found or rule disabled, return true (allow).
2. Build BucketConfiguration: `BucketConfiguration.builder().addLimit(Bandwidth.classic(rule.getThreshold(), Refill.intervally(rule.getThreshold(), Duration.ofSeconds(rule.getWindowSeconds())))).build()`
3. Key: `("fraud:velocity:" + signal.getSignalName() + ":" + identifier).getBytes(StandardCharsets.UTF_8)`
4. `Bucket bucket = proxyManager.builder().build(key, () -> config)`
5. `return bucket.tryConsume(1)` — true = allowed, false = blocked

**FraudScoringService.java** — `@Service`. Constructor injects `VelocityCheckService velocityCheckService` and `FraudRuleCache fraudRuleCache`.

Public method `FraudDecision evaluate(PaymentCommand cmd)`:
1. Check IP velocity: `boolean ipAllowed = velocityCheckService.checkVelocity(FraudSignal.IP_VELOCITY, cmd.clientIp())`
2. Check MSISDN velocity: `boolean msisdnAllowed = velocityCheckService.checkVelocity(FraudSignal.MSISDN_VELOCITY, cmd.msisdn())`
3. Check APP velocity using tenantId as key: `boolean appAllowed = velocityCheckService.checkVelocity(FraudSignal.APP_VELOCITY, cmd.tenantId().toString())`
4. Compute weighted score: iterate `fraudRuleCache.getRules()`, for each enabled rule with a matching signal that was violated (IP/MSISDN/APP), add its weight. Clamp to Math.min(rawScore, 100).
5. Determine block: load BLOCK_THRESHOLD rule via `fraudRuleCache.findBySignalName("BLOCK_THRESHOLD")`. Default threshold = 70 if not found. Block if `riskScore >= blockThreshold`.
6. If blocked, return `FraudDecision.block(riskScore, "Velocity limit exceeded: " + firstBlockedSignal)`.
7. Else return `FraudDecision.allow(riskScore)`.

Parse device fingerprint from `cmd.deviceFingerprint()` and `cmd.userAgent()` — no additional processing needed in FraudScoringService; the fingerprint is just carried on the command and stored by the orchestrator in Plan 07-02.
