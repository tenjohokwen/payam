<objective>
Second infrastructure move wave of Phase 65. Relocate the "utility layer" common sub-packages — `common.client` (8 files including exception/ sub-subpackage), `common.threadpool` (5 files), `common.util` (6 files), `common.validation` (18 files), `common.dto.PhoneNumberDto` (1 file → goes to `infrastructure.validation`) — to their respective `infrastructure.*` sub-packages. Also relocate the 5 root-level common utility files (`ClockProvider`, `Constants`, `Predicate`, `TimeGuru`, `TransactionIdProvider`) to `infrastructure.util`.

This wave depends on Plan 01 (`common.exception`, `common.message`, `common.config`, `common.logging` already at `infrastructure.*`) because:
- `HttpClientException` + `MomoError` import `common.exception.{ApplicationException,ErrorCode}` — after Plan 01 these are at `infrastructure.exception.*`
- `JsonUtil` imports `common.config.CommonConfig` + `common.exception.{ApplicationException,ErrorCode}` — after Plan 01 both are at `infrastructure.*`
- `CamMobileValidator` imports `common.exception.{ApplicationException,ErrorCode}` — Plan 01 ensures these are at the new path

This wave also relocates 4 test utility files (`TestClockProvider`, `BodySanitizerTest`, `CamMobileValidatorTest`, `InputValidatorTest`) because:
- `TestClockProvider.java` calls `ClockProvider.setClock()` — a package-private method. To preserve the package-private access, `TestClockProvider` must live in the SAME package as `ClockProvider` in production. Both target `com.softropic.payam.infrastructure.util` (research Pitfall 6).
- The other three test files test classes that move in this wave.

Purpose: After this plan, the entire infrastructure-scoped portion of `common/` is gone. The only files remaining in `common/` will be the payment-domain types (Plan 03) and the security-domain types + dead-code enums (Plan 04). This sets up the final cleanup phase.

Output: 37 new production files under `infrastructure.{client,threadpool,util,validation}`; 4 test utility files relocated under `test/.../infrastructure/{util,validation}`; ~50-60 caller files updated; 1 FQN body reference fixed in `MtnMoMoClient.java` line 171; `mvn verify` green (BUILD-01). After this plan, `common/` contains only: `payment/`, `refund/`, `enums/`, `consumer/`, and `Gender.java`.
</objective>
