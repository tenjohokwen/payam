  <name>Task 1: Rewrite LoggingFilter with structured lifecycle events and requestId MDC</name>
  <files>src/main/java/com/softropic/payam/security/audit/filter/LoggingFilter.java</files>
  <action>
Fully rewrite LoggingFilter.java. The existing implementation logs raw header dumps using string interpolation — replace the entire body. Keep the class name, package, constructor signature (accepts List&lt;String&gt; ignoredStaticResources), and shouldNotFilter() logic. Everything else is replaced.

**New doFilterInternal() logic:**

1. Generate requestId: read the X-Request-Id header (Constants.REQUEST_ID_HEADER_NAME = "X-Request-Id") from the request. If blank, generate UUID.randomUUID().toString(). Store as local variable.

2. Set MDC BEFORE the first log call:
   MDC.put(Constants.REQUEST_ID_NAME, requestId);  // "requestId"

3. Derive operation string via a private method deriveOperation(String method, String path):
   - if path.startsWith("/v1/payments") and method is POST → "initiate_payment"
   - if path.startsWith("/v1/callbacks/orange") → "orange_callback"
   - if path.startsWith("/v1/callbacks/mtn") → "mtn_callback"
   - if path.startsWith("/v1/admin/transactions") → "admin_transactions"
   - if path.startsWith("/v1/admin/metrics") → "admin_metrics"
   - if path.startsWith("/v1/account") → "account_" + method.toLowerCase()
   - fallback: method.toLowerCase() + "_" + path.replace("/", "_").replaceAll("^_", "").replaceAll("_+$", "")
   Operation must be low-cardinality — no UUIDs, amounts, or per-request data.

4. Derive clientIp via a private method resolveClientIp(HttpServletRequest request):
   - Read "Forwarded" header first; if blank, fall back to request.getRemoteAddr()
   - Same pattern as RequestMetadataProvider.initRequestMetadata() lines 55-59.

5. Emit request_start event BEFORE calling filterChain.doFilter():
   log.info("Request received",
       kv("event",     "request_start"),
       kv("operation", operation),
       kv("method",    method),
       kv("path",      path),
       kv("requestId", requestId),
       kv("clientIp",  clientIp));

6. Record startMs = System.currentTimeMillis() before filterChain.doFilter().

7. Wrap chain in try/finally:
   - try: call filterChain.doFilter(request, response)
   - After chain returns (still in try, before finally): read durationMs, httpStatus, tenantId
     - durationMs = System.currentTimeMillis() - startMs
     - httpStatus = response.getStatus()
     - tenantId = TenantContext.get()  // may be null for JWT paths — that is expected
     - if httpStatus >= 500:
         log.error("Request error",
             kv("event",      "request_error"),
             kv("operation",  operation),
             kv("durationMs", durationMs),
             kv("errorCode",  "HTTP_" + httpStatus),
             kv("status",     "ERROR"),
             kv("httpStatus", httpStatus));
     - else:
         // Build args list to conditionally include tenantId
         List&lt;Object&gt; args = new ArrayList&lt;&gt;();
         args.add(kv("event",      "request_end"));
         args.add(kv("operation",  operation));
         args.add(kv("durationMs", durationMs));
         args.add(kv("status",     "SUCCESS"));
         args.add(kv("httpStatus", httpStatus));
         if (tenantId != null) args.add(kv("tenantId", tenantId));
         log.info("Request completed", args.toArray());
   - finally: MDC.remove(Constants.REQUEST_ID_NAME)  // ONLY remove this key — never MDC.clear()

**Async dispatch:** If isAsyncDispatch(request) is true, delegate directly to filterChain.doFilter(request, response) and return — no MDC, no lifecycle events for async re-entry.
