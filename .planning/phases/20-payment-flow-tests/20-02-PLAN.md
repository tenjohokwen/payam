  ```java

  noRetryRestTemplate.setErrorHandler(new DefaultResponseErrorHandler() {
      @Override
      public boolean hasError(HttpStatusCode statusCode) { return false; }
  });
  ```
  This matches the pattern from `PaymentOrchestratorIT.noRetryRestTemplate`.

`injectFault()`:
- Force the MTN circuit breaker to OPEN state directly (no need to trip it via failures — simpler and deterministic):
  ```java
  circuitBreakerRegistry.circuitBreaker("mtn").transitionToOpenState();
  ```
- Flush Redis to clear any RESERVED idempotency keys that might cause a 409/202 response before the CB check:
  ```java
  redis.getConnectionFactory().getConnection().serverCommands().flushDb();
  ```
- Re-stub the MTN token endpoint (Redis flush cleared the cached token):
  ```java
  mtnServer.stubFor(post(urlPathEqualTo("/token/"))
      .willReturn(okJson(WireMockConfig.MTN_TOKEN_RESPONSE)));
  ```

`executeFlow()`:
- Build MTN request and idempotency key
- POST /v1/payments using `noRetryRestTemplate` (NOT testRestTemplate):
  ```java
  HttpHeaders headers = new HttpHeaders();
  headers.setContentType(MediaType.APPLICATION_JSON);
  headers.set("X-Api-Key", tenant.rawApiKey());
  ResponseEntity<String> response = noRetryRestTemplate.exchange(
      "http://localhost:" + serverPort + "/v1/payments",
      HttpMethod.POST,
      new HttpEntity<>(requestJson, headers),
      String.class);
  ```

- Assert circuit breaker is still OPEN: `assertThat(circuitBreakerRegistry.circuitBreaker("mtn").getState()).isEqualTo(CircuitBreaker.State.OPEN);`

Fields:
```java
@Autowired TenantService tenantService;
@Autowired TenantRepository tenantRepository;
@Autowired JdbcTemplate jdbcTemplate;
private DeterministicUuidFactory uuidFactory;
```

Method: `@Test void idempotency_three_round_scenario()`

**Before test starts — shared stubs:**
- Stub MTN initiation endpoints on `mtnServer` (account holder + requestToPay + double-check status):
  ```java
  mtnServer.stubFor(get(urlPathMatching("/v1_0/accountholder/MSISDN/.*/basicuserinfo"))
      .willReturn(okJson("{}")));
  mtnServer.stubFor(post(urlPathEqualTo("/v1_0/requesttopay"))
      .willReturn(aResponse().withStatus(202)));
  ```
- `uuidFactory = new DeterministicUuidFactory(0xCAFEBL);`

**Round 1 — new creation:**
- Create tenant A: `TenantBuilder.CreatedTenant tenantA = new TenantBuilder().withName("Idempotency-A").create(tenantService, tenantRepository);`
- Build request with fixed idempotency key:
  ```java
  PaymentRequest req = new PaymentRequestBuilder()
      .withDeterministicIdempotencyKey(uuidFactory)
      .build();
  String idempotencyKey = req.idempotencyKey();
  ```
- POST /v1/payments with tenantA API key → assert 202
- Capture `transactionId1` from response
- Assert `transactionId1` is not null

**Round 2 — duplicate same tenant:**
- POST /v1/payments AGAIN with same request body and same `X-Api-Key: tenantA.rawApiKey()`
- Assert 202 response
- Capture `transactionId2` from response
- Assert `transactionId2.equals(transactionId1)` — same transaction returned
- Assert `mtnServer.verify(1, postRequestedFor(urlPathEqualTo("/v1_0/requesttopay")))` — provider called exactly ONCE across both rounds; second request hit the idempotency cache

**Round 3 — cross-tenant, same idempotency key:**
- Create tenant B: `TenantBuilder.CreatedTenant tenantB = new TenantBuilder().withName("Idempotency-B").create(tenantService, tenantRepository);`
- POST /v1/payments with SAME request body (same idempotency key) but `X-Api-Key: tenantB.rawApiKey()`
- Assert 202 response
- Capture `transactionId3` from response
- Assert `!transactionId3.equals(transactionId1)` — different transaction for different tenant
- Assert tenant isolation — tenant B cannot see tenant A's transaction:
  ```java
  new TenantIsolationVerifier(jdbcTemplate)
      .assertNoDataLeaksToOtherTenant(tenantA.tenantId(), tenantB.tenantId(), transactionId1);
  ```
- Assert provider called exactly TWICE total (once for tenantA Round 1, once for tenantB Round 3):
  `mtnServer.verify(2, postRequestedFor(urlPathEqualTo("/v1_0/requesttopay")));`
  </action>
