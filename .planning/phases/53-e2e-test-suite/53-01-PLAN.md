```java
public record DisbursementRequest(
    String recipientMsisdn,   // E.164, e.g. "+237671234567"
    BigDecimal amount,        // XAF
    String currency,          // "XAF"
    String reference,         // tenant ref, max 50
    String description,       // optional, max 140
    String metadata,          // optional, max 2048
    String idempotencyKey     // populated by controller from Idempotency-Key header
) {}
```

DisbursementResponse (record):
```java
public record DisbursementResponse(
    String disbursementId,    // our internal id
    String status,            // "PROCESSING" | "PENDING_CONFIRMATION" | "FAILED"
    String providerRef,       // null until provider responds
    String recipientMsisdn,
    BigDecimal amount, BigDecimal fee, String currency, String reference,
    String provider,          // "MTN" | "ORANGE"
    String errorCode,         // null on success
    String errorMessage
) {}
```

DisbursementResource HTTP contract:
- POST /v1/disbursements — body=DisbursementRequest JSON, headers: X-Api-Key, Idempotency-Key. Returns 202 on success or DISBURSEMENT_ALREADY_PROCESSING.
- PUT /v1/callbacks/mtn/disbursement/{providerRef} — body has externalId, status, financialTransactionId. Always returns 200. Authenticated via callback IP whitelist (empty list disables in tests).
- GET /v1/disbursements/{id} — header X-Api-Key. 404 if wrong tenant.

MTN callback statuses (from MtnDisbursementCallbackControllerIT):
- "SUCCESSFUL" → maps to DisbursementStatus.SUCCESS
- "FAILED" → maps to DisbursementStatus.FAILED

MTN double-check stub URL pattern (must be stubbed for callback transition to commit):
- GET .*/transfer/{providerRef} returning JSON: `{"financialTransactionId":"FT-1","externalId":"ext","amount":"5000","currency":"XAF","payee":{"partyIdType":"MSISDN","partyId":"237671234567"},"status":"SUCCESSFUL"}`

MTN initiate stub URLs:
- GET /v1_0/accountholder/MSISDN/.*  → 200 `{}`  (validateAccountHolder)
- POST /v1_0/transfer  → 202  (initiateDisbursement)
- POST /token/collection  → access_token JSON
- POST /token/disbursement  → access_token JSON

DisbursementRepository.findByDisbursementId(String) returns Optional<Disbursement> with getDisbursementStatus().

MerchantWalletBalanceRepository.findByTenantId(Long) returns Optional<MerchantWalletBalance> with getReservedAmount(), getBalance().

TenantService.createTenant(name, ApiKeyEnvironment.PROD) returns TenantCreationResult with .tenant().getId() and .rawKey() (used as X-Api-Key value).
