    STEP 1 — TlsStartupAssertion:

    Create TlsStartupAssertion.java in ops package (com.softropic.payam.ops).
    Implements ApplicationListener&lt;ApplicationReadyEvent&gt;. @Component. @RequiredArgsConstructor.
    Inject: OrangeMoneyConfig orangeConfig, MtnMoMoConfig mtnConfig, Environment env.

    onApplicationEvent(ApplicationReadyEvent event):
    1. if (Arrays.asList(env.getActiveProfiles()).contains("dev")) return;  // Pitfall 1 fix
    2. Read OrangeMoneyConfig: the config references ClientConfiguration; read source to find
       the exact path to TcpConfiguration.checkCertificate before implementing.
       Typical path: orangeConfig.getClientConfiguration().getTcpConfiguration().isCheckCertificate()
       or similar. READ THE SOURCE FILE before coding this.
    3. Read MtnMoMoConfig the same way.
    4. If either returns false: throw new AppSetupException(
       "TLS certificate verification is disabled for one or more providers. " +
       "Set checkCertificate: true in application.yaml for production deployments.");
    5. log.info("TLS assertion passed — all provider connections have checkCertificate=true");

    NOTE: AppSetupException must be RuntimeException subclass — verify from its source.
    Throwing from ApplicationReadyEvent.onApplicationEvent() closes the application context
    when it is a RuntimeException.

    STEP 2 — ProviderStatusDto:

    Record or final class in admin.contract package:
    public record ProviderStatusDto(String state, float failureRate,
    int bufferedCalls, int failedCalls) {}

    STEP 3 — ProviderStatusResource:

    @RestController @RequestMapping("/v1/admin/providers")
    @PreAuthorize(SecurityConstants.HAS_ADMIN_ROLE) @RequiredArgsConstructor.
    Inject CircuitBreakerRegistry circuitBreakerRegistry.

    GET /v1/admin/providers/status:
    1. Force-create both known CBs to handle Pitfall 5 (lazy creation):
       CircuitBreaker orange = circuitBreakerRegistry.circuitBreaker("orange");
       CircuitBreaker mtn = circuitBreakerRegistry.circuitBreaker("mtn");
    2. Iterate circuitBreakerRegistry.getAllCircuitBreakers() to build a LinkedHashMap.
    3. For each CB, build ProviderStatusDto(cb.getState().name(),
       cb.getMetrics().getFailureRate(), cb.getMetrics().getNumberOfBufferedCalls(),
       cb.getMetrics().getNumberOfFailedCalls()).
    4. Return ResponseEntity.ok(Map&lt;String, ProviderStatusDto&gt;).

    STEP 4 — HashChainResultDto + HashChainAuditSummaryDto:

    HashChainResultDto: record with transactionId (String), valid (boolean).
    HashChainAuditSummaryDto: record with total (int), valid (int),
    violations (List&lt;String&gt; — transactionIds with invalid chains).

    STEP 5 — PaymentEventLogRepository (add distinct query):

    Add one JPQL query method to the existing PaymentEventLogRepository interface:
    @Query("SELECT DISTINCT e.transactionId FROM PaymentEventLog e")
    List&lt;String&gt; findAllDistinctTransactionIds();

    STEP 6 — AuditResource:

    @RestController @RequestMapping("/v1/admin/audit")
    @PreAuthorize(SecurityConstants.HAS_ADMIN_ROLE) @RequiredArgsConstructor.
    Inject EventLogService eventLogService, PaymentEventLogRepository eventLogRepository.

    GET /v1/admin/audit/hash-chain/{transactionId}:
    Call eventLogService.verifyChain(transactionId). Return HashChainResultDto.
    If verifyChain throws any exception (transactionId not found), return
    ResponseEntity.status(404).body(new HashChainResultDto(transactionId, false)).

    GET /v1/admin/audit/hash-chain (full audit with optional date window):
    Accept optional @RequestParam(required=false) String from and String to (ISO date strings).
    For Phase 10, implement without date filtering (Pitfall 7 is a production concern; note
    in javadoc that a large event log may be slow). Iterate findAllDistinctTransactionIds(),
    call verifyChain() for each, collect results.
    Return HashChainAuditSummaryDto with total, valid count, and list of violating transactionIds.
    Add @Transactional(readOnly=true) on this method — iterates many rows.
