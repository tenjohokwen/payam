    STEP 7 — FeeEvaluationService:

    @Service. Inject FeeRuleCache. One public method:
    BigDecimal evaluateFee(Long tenantId, BigDecimal amount):
    - Find rule via feeRuleCache.findForTenant(tenantId)
    - If rule present and feeType is FEE_FIXED: return rule.getFixedAmount()
    - If rule present and feeType is FEE_PERCENTAGE: return amount.multiply(rule.getPercentageRate())
      .divide(BigDecimal.valueOf(100), 2, RoundingMode.HALF_UP)
    - If no rule: return BigDecimal.ZERO
    Also expose a method findRuleForTenant(Long tenantId): Optional&lt;FeeRule&gt; (for storing fee_rule_id
    on the transaction).
