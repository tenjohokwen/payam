    MtnMoMoClient.java — extends AbstractClient. Constructor: public MtnMoMoClient(MtnMoMoConfig config). Pass config.getCollectionBaseUrl() as the baseUrl to super(). Do NOT add FormHttpMessageConverter (MTN token endpoint accepts no form body — unlike Orange).

    Methods:

    fetchCollectionToken() — returns MtnTokenResponse:
      Build "Basic " + Base64(apiUserId + ":" + apiKey) header.
      POST to config.getCollectionTokenUrl() with Authorization header and Ocp-Apim-Subscription-Key = collectionSubscriptionKey.
      Body is null (MTN token endpoint MUST NOT receive a form body — this is Pitfall 4 from research; sending form body returns 400).
      On non-2xx or null body: throw MtnApiException("Failed to fetch MTN collection token — status: " + statusCode).

    fetchDisbursementToken() — returns MtnTokenResponse:
      Same as fetchCollectionToken() but uses config.getDisbursementTokenUrl() and config.getDisbursementSubscriptionKey().
      Separate method because disbursement uses a completely different product key and endpoint.

    requestToPay(String referenceId, RequestToPayRequest request, String bearerToken) — returns void (202):
      URL: config.getCollectionBaseUrl() + "/v1_0/requesttopay"
      Headers: Authorization Bearer, X-Reference-Id = referenceId, X-Target-Environment = config.getTargetEnvironment(), Ocp-Apim-Subscription-Key = config.getCollectionSubscriptionKey(), Content-Type application/json.
      POST with request body. MTN returns 202 Accepted with no body.
      On non-202: throw MtnApiException("requestToPay failed — referenceId: " + referenceId + ", status: " + statusCode).
      Note: 202 is the success code for RequestToPay, not 200. Check response.getStatusCode().value() == 202 OR response.getStatusCode().is2xxSuccessful().

    getRequestToPayStatus(String referenceId, String bearerToken) — returns RequestToPayStatusResponse:
      URL: config.getCollectionBaseUrl() + "/v1_0/requesttopay/" + referenceId
      Headers: Authorization Bearer, X-Target-Environment, Ocp-Apim-Subscription-Key = collectionSubscriptionKey.
      GET, no body.
      On non-2xx or null body: throw MtnApiException.

    validateAccountHolder(String msisdn, String bearerToken) — returns AccountHolderInfoResponse:
      URL: config.getCollectionBaseUrl() + "/v1_0/accountholder/MSISDN/" + msisdn + "/basicuserinfo"
      Headers: Authorization Bearer, X-Target-Environment, Ocp-Apim-Subscription-Key = collectionSubscriptionKey.
      GET, no body.
      On 404: throw MtnAccountInactiveException(msisdn). On other non-2xx: throw MtnApiException.
      Note: MTN returns 404 (not a body with status=INACTIVE) for inactive accounts — this is the key difference from Orange's subscriber validation.

    getBalance(String bearerToken) — returns AccountBalanceResponse:
      URL: config.getCollectionBaseUrl() + "/v1_0/account/balance"
      Headers: Authorization Bearer, X-Target-Environment, Ocp-Apim-Subscription-Key = collectionSubscriptionKey.
      GET, no body.
      On non-2xx or null body: throw MtnApiException.

    disburse(String referenceId, DisbursementRequest request, String bearerToken) — returns void:
      URL: config.getDisbursementBaseUrl() + "/v1_0/transfer"
      Headers: Authorization Bearer, X-Reference-Id = referenceId, X-Target-Environment, Ocp-Apim-Subscription-Key = config.getDisbursementSubscriptionKey() (NOT collection key — Pitfall 5).
      POST, 202 accepted.
      On non-202: throw MtnApiException.

    Private helper mtnHeaders(String bearerToken, String referenceId, String subscriptionKey):
      Returns HttpHeaders with Authorization, X-Reference-Id (skip if null), X-Target-Environment, Ocp-Apim-Subscription-Key, Content-Type.
