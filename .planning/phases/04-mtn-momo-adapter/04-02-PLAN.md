    MtnMoMoPort.java — @Service, implements MobileMoneyPort. Constructor takes:
      (MtnMoMoClient mtnMoMoClient, MtnTokenService mtnTokenService,
       TransactionRepository transactionRepository, EventLogService eventLogService,
       MtnMoMoConfig config)

      initiateMerchantPayment(PaymentCommand cmd):
        NOT @Transactional (same as OrangeMoneyPort — caller already committed INITIATED row, P1.1).
        @CircuitBreaker(name = "mtn") @Retry(name = "mtn") — no fallbackMethod (same decision as Orange, 03-02).

        1. Validate account holder: call mtnMoMoClient.validateAccountHolder(msisdn, token).
           Catch MtnAccountInactiveException: rethrow as-is (circuit breaker ignores it per config).
        2. Generate referenceId: String referenceId = UUID.randomUUID().toString()
        3. Persist referenceId BEFORE API call: persistProviderRef(cmd.transactionId(), referenceId)
           This is the critical difference from Orange — MTN's providerRef is merchant-generated, so it
           must be stored before the call to survive a crash (Pitfall 6 from research).
        4. Build RequestToPayRequest: amount = cmd.amount().toPlainString(), currency = cmd.currency(),
           externalId = cmd.transactionId(), payer = new Party("MSISDN", stripPlus(cmd.msisdn())),
           payerMessage = "Payment via Payam", payeeNote = cmd.externalReference() != null ? cmd.externalReference() : cmd.transactionId()
        5. Call mtnMoMoClient.requestToPay(referenceId, request, token) — returns void on 202.
        6. Append event log: PAYMENT_INITIATED, INITIATED -> PROCESSING, actor "MTN_ADAPTER".
        7. Return ProviderResult.pending(referenceId, "PENDING").

      getTransactionStatus(String providerRef):
        @Transactional @CircuitBreaker(name = "mtn") (no fallback).
        token = mtnTokenService.getAccessToken()
        response = mtnMoMoClient.getRequestToPayStatus(providerRef, token)
        rawStatus = response.getStatus()
        internal = MtnStatusMapper.toInternal(rawStatus)
        pending = internal == TransactionStatus.PROCESSING
        return pending ? ProviderResult.pending(providerRef, rawStatus) : ProviderResult.success(providerRef, rawStatus)

      validateSubscriber(String msisdn):
        token = mtnTokenService.getAccessToken()
        try {
            mtnMoMoClient.validateAccountHolder(stripPlus(msisdn), token)
            return new SubscriberStatus(true, msisdn, "ACTIVE")
        } catch (MtnAccountInactiveException e) {
            return new SubscriberStatus(false, msisdn, "INACTIVE")
        }
        Note: MTN returns 404 for inactive accounts (no JSON body). MtnMoMoClient converts 404 -> MtnAccountInactiveException. No "ACTIF"/"INACTIF" body parsing needed.

      processCallback(MtnCallbackPayload payload):
        Public method for MtnCallbackController use — NOT part of MobileMoneyPort interface.
        log.info("MTN callback received: externalId={}, status={}", payload.getExternalId(), payload.getStatus())
        Correlation uses payload.getExternalId() (= our transactionId). Phase 6 double-check will call
        getTransactionStatus(providerRef) before applying any state transition.
        For now: log the callback and return — Phase 6 wires full webhook processing.
        Store financialTransactionId if not null (for reconciliation):
          if (payload.getFinancialTransactionId() != null) { storeFinancialTxId(payload.getExternalId(), payload.getFinancialTransactionId()); }

      Private helpers:
        stripPlus(String msisdn): removes leading '+' only. "+237692954629" -> "237692954629"
        Note: MTN accepts full country code without '+'. Unlike Orange which strips "+237".

        @Transactional(propagation = Propagation.REQUIRES_NEW)
        protected void persistProviderRef(String transactionId, String providerRef):
          transactionRepository.findByTransactionId(transactionId).ifPresent(tx -> {
              tx.setProviderRef(providerRef); transactionRepository.save(tx); });

        @Transactional(propagation = Propagation.REQUIRES_NEW)
        protected void storeFinancialTxId(String transactionId, String financialTxId):

          Simplest: transactionRepository.findByTransactionId(transactionId).ifPresent(tx -> {
              tx.setMtnFinancialTxId(financialTxId); transactionRepository.save(tx); });
          Note: If Transaction entity does not yet have setMtnFinancialTxId(), add it now (the V7 migration added the column).

    MtnIpWhitelistInterceptor.java — @Component, implements HandlerInterceptor:
      Constructor: (MtnMoMoConfig config). Store config.getCallbackIpWhitelist() as Set<String>.

      @Override
      public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler):
        // Extract client IP — respect X-Forwarded-For (server.forward-headers-strategy=native is set)
        String ip = request.getHeader("X-Forwarded-For");
        if (ip == null || ip.isBlank()) ip = request.getRemoteAddr();
        // Take first IP if comma-separated proxy chain
        ip = ip.split(",")[0].trim();

        if (allowedIps.isEmpty()) {
            // Empty whitelist = sandbox mode (accept all) — log warning
            log.warn("MTN callback IP whitelist is empty — accepting all IPs (sandbox mode)");
            return true;
        }
        // Simple exact-match check. CIDR matching will be added when production IP ranges are confirmed.
        // For now: exact IP match or CIDR prefix match using simple string contains is sufficient for sandbox.
        boolean allowed = allowedIps.stream().anyMatch(allowed -> {
            if (allowed.contains("/")) {
                // Minimal CIDR: check if IP starts with network prefix (sufficient for /8 ranges)
                String prefix = allowed.substring(0, allowed.indexOf('/'));
                String[] parts = prefix.split("\\.");
                // For /8: check first octet; for /16: first two octets; etc.
                int maskBits = Integer.parseInt(allowed.substring(allowed.indexOf('/') + 1));
                int octets = maskBits / 8;
                String[] ipParts = ip.split("\\.");
                if (ipParts.length < octets || parts.length < octets) return false;
                for (int i = 0; i < octets; i++) {
                    if (!ipParts[i].equals(parts[i])) return false;
                }
                return true;
            }
            return allowed.equals(ip);
        });

        if (!allowed) {
            log.warn("MTN callback rejected — IP not whitelisted: {}", ip);
            response.setStatus(HttpServletResponse.SC_FORBIDDEN);
            return false;
        }
        return true;
