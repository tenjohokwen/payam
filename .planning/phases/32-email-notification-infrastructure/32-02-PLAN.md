**A. Create `TenantLifecycleEmailListener.java`** in package `com.softropic.payam.email.infrastructure.listener`.

Follow `PlatformConfigEmailListener` pattern exactly: `@Slf4j @Component`, constructor-injected `ApplicationEventPublisher publisher` and `@Value("${payam.platform.notification-email}") String notificationEmail`.

Three `@Transactional @EventListener` methods:

**Method 1: `onApiKeyEvent(TenantApiKeyEvent event)`**
- Map `TenantApiKeyEvent.Action` to `EmailTemplate`:
  - `GENERATED` -> `EmailTemplate.TENANT_API_KEY_GENERATED`
  - `ROTATED` -> `EmailTemplate.TENANT_API_KEY_ROTATED`
  - `REVOKED` -> `EmailTemplate.TENANT_API_KEY_REVOKED`
  - `REACTIVATED` -> `EmailTemplate.TENANT_API_KEY_REACTIVATED`
- Build data map with keys: `tenantName`, `keyPrefix`, `environment`, and the timestamp key matching the action (`generatedAt`, `rotatedAt`, `revokedAt`, or `reactivatedAt`), plus `helpCode` from `ShortCode.shortenInt(UUID.randomUUID().hashCode())`
- Build recipients list: always include admin recipient (`notificationEmail`, langKey "en"). If `event.tenantEmail() != null`, add second `Recipient` with that email and langKey "en".
- Create `Envelope` with recipients, template, deadline `Instant.now(ClockProvider.getClock()).plus(Duration.ofDays(7))`, data map, sendId = helpCode
- `publisher.publishEvent(envelope)`
- Log: `log.info("Dispatching tenant API key notification email", kv("action", event.action()), kv("keyPrefix", event.keyPrefix()), kv("event", "tenant_api_key_email_dispatched"))`

**Method 2: `onStatusChanged(TenantStatusChangedEvent event)`**
- Always use `EmailTemplate.TENANT_STATUS_CHANGED`
- Build data map: `tenantName`, `eventType` (event.eventType().name()), `changedAt` (event.occurredAt().toString()), plus `oldValue` and `newValue` if non-null, plus `helpCode`
- Recipient routing varies by eventType (per D-03):
  - `EMAIL_CHANGED`: admin recipient + OLD address recipient (use `event.oldValue()` as the tenant email, NOT `event.tenantEmail()`). If `event.oldValue()` is null, admin only.
  - All others (`SUSPENDED`, `REACTIVATED`, `WEBHOOK_URL_CHANGED`): admin + tenant (event.tenantEmail()) if non-null
- Create and publish Envelope
- Log: `log.info("Dispatching tenant status change notification email", kv("eventType", event.eventType()), kv("event", "tenant_status_change_email_dispatched"))`

**Method 3: `onWebhookSecretRegenerated(TenantWebhookSecretRegeneratedEvent event)`**
- Use `EmailTemplate.TENANT_WEBHOOK_SECRET_REGENERATED`
- Build data map: `tenantName`, `regeneratedAt` (event.occurredAt().toString()), `helpCode`
- Recipients: admin + tenant (if non-null)
- Create and publish Envelope
- Log: `log.info("Dispatching webhook secret regenerated notification email", kv("event", "tenant_webhook_secret_email_dispatched"))`

**Helper method: `private List<Recipient> buildRecipients(String tenantEmail)`**
- Create admin `Recipient` with `notificationEmail` and langKey "en" (no firstname/lastname — matches PlatformConfigEmailListener pattern per D-01)
- If `tenantEmail != null`, create tenant `Recipient` with that email and langKey "en"
- Return list of 1 or 2 recipients
