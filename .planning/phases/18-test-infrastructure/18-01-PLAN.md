Create three specialisation classes. All in package `com.softropic.payam.e2e`.

**AbstractPaymentFlowTest.java**

Extends `AbstractPayamE2ETest`. No class-level annotations (inherits from base).

Single `@Test final void runFlow()` method that calls in order:
1. `setupPreconditions()`
2. `executeFlow()`
3. `simulateProviderCallback()`
4. `verifyFinalState()`

Four `protected abstract` methods: `setupPreconditions()`, `executeFlow()`, `simulateProviderCallback()`, `verifyFinalState()` — all return void, no parameters.

`final` on `runFlow()` is mandatory — prevents subclasses from accidentally overriding the orchestration.

---

**AbstractWebhookFlowTest.java**

Extends `AbstractPaymentFlowTest`.

Overrides `simulateProviderCallback()` as `final`:
```java
@Override
protected final void simulateProviderCallback() {
    dispatchInboundWebhook();
}
```

Overrides `verifyFinalState()` as `final`:
```java
@Override
protected final void verifyFinalState() {
    verifyDoubleCheckTriggered();
    verifyTransactionState();
}
```

Adds three `protected abstract` methods: `dispatchInboundWebhook()`, `verifyDoubleCheckTriggered()`, `verifyTransactionState()` — all return void.

Subclasses implement all four from AbstractPaymentFlowTest EXCEPT simulateProviderCallback and verifyFinalState (which are now final here): they implement `setupPreconditions`, `executeFlow`, `dispatchInboundWebhook`, `verifyDoubleCheckTriggered`, `verifyTransactionState`.

---

**AbstractFailureFlowTest.java**

Extends `AbstractPayamE2ETest` directly (NOT AbstractPaymentFlowTest — failure flows are a different structure).

Single `@Test final void runFailureScenario()` method that calls in order:
1. `setupPreconditions()`
2. `injectFault()`
3. `executeFlow()`
4. `verifyFailureHandled()`

Four `protected abstract` methods: `setupPreconditions()`, `injectFault()`, `executeFlow()`, `verifyFailureHandled()` — all return void.

`final` on `runFailureScenario()` is mandatory.

---

For all three files, only import what is actually used. AbstractPaymentFlowTest and AbstractWebhookFlowTest only need `org.junit.jupiter.api.Test`. AbstractFailureFlowTest also only needs `org.junit.jupiter.api.Test`. No Spring annotations needed on these classes.
