# Plan 34-01: Core domain changes — description field + PlatformConfigService.findByProvider()

## Objective

Extend the core payment domain to carry an optional `description` field from the API surface
(`PaymentRequest`) through the command object (`PaymentCommand`) to the orchestrator, so the
Orange adapter can pass it to Orange as a human-readable payment description. Also add
`PlatformConfigService.findByProvider()` so the Orange adapter can look up the channel MSISDN
stored in the platform config table. Finally, update `PaymentRequestBuilder` (test helper) and
all non-Orange `PaymentCommand` construction sites to compile cleanly after the record is
extended.

This plan produces no visible behaviour change — it is pure plumbing. Plan 34-02 wires the new
field and the new service method into the Orange adapter.

### Step 4: Add `PlatformConfigService.findByProvider(String)`

**File:** `src/main/java/com/softropic/payam/platform/service/PlatformConfigService.java`
**Action:** modify

Add the following method after `findAll()`:

```java
/**
 * Returns the platform config DTO for the given provider.
 *
 * @param provider provider key (case-insensitive; normalised to upper-case internally)
 * @return the DTO for the requested provider
 * @throws IllegalStateException if no config row exists for the given provider
 */
@Transactional(readOnly = true)
public PlatformConfigDto findByProvider(String provider) {
    String upper = provider.toUpperCase();
    return platformConfigRepository.findByProvider(upper)
            .map(c -> new PlatformConfigDto(c.getProvider(), c.getPlatformMsisdn()))
            .orElseThrow(() -> new IllegalStateException(
                "Platform MSISDN not configured for provider: " + provider));
}
```

No additional imports needed — `PlatformConfigDto`, `PlatformConfigRepository`, and
`@Transactional` are already imported.

### Step 5: Add `findByProvider` tests to `PlatformConfigServiceTest`

**File:** `src/test/java/com/softropic/payam/platform/service/PlatformConfigServiceTest.java`
**Action:** modify

Add two new test methods to the existing test class (after the two existing `update_*` tests):

```java
@Test
void findByProvider_shouldReturnDtoWhenProviderExists() {
    // Given
    PlatformConfig config = PlatformConfig.builder()
            .provider("ORANGE")
            .platformMsisdn("652000001")
            .status(EntityStatus.ACTIVE)
            .build();
    when(platformConfigRepository.findByProvider("ORANGE")).thenReturn(Optional.of(config));

    // When
    PlatformConfigDto result = platformConfigService.findByProvider("ORANGE");

    // Then
    assertThat(result.provider()).isEqualTo("ORANGE");
    assertThat(result.platformMsisdn()).isEqualTo("652000001");
}

@Test
void findByProvider_shouldThrowIllegalStateWhenProviderNotFound() {
    // Given
    when(platformConfigRepository.findByProvider("ORANGE")).thenReturn(Optional.empty());

    // When / Then
    org.junit.jupiter.api.Assertions.assertThrows(
        IllegalStateException.class,
        () -> platformConfigService.findByProvider("ORANGE"),
        "Platform MSISDN not configured for provider: ORANGE"
    );
}
```

Import `org.junit.jupiter.api.Assertions` if not already present (or use the AssertJ style
`assertThatThrownBy(...).isInstanceOf(IllegalStateException.class)` — either is fine).
