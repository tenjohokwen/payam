**PaymentOrchestrator.java** — wire fee fields at the two construction sites:

The fee is computed and saved in the `transactionTemplate.execute()` block (lines 174–184). The `locked` variable holds the saved `Transaction` with `feeAmount` set. However, `locked` is local to that lambda and not visible after. The cleanest approach: after the `transactionTemplate.execute()` block completes, reload the fee from the DB — but simpler: capture fee values in local variables inside the lambda and write them to `final` captured variables using an array holder:

```java
// Capture fee values from the transactionTemplate block for use in PaymentResponse
BigDecimal[] capturedFee = {BigDecimal.ZERO};
Long[] capturedFeeRuleId = {null};

transactionTemplate.execute(status -> {
    Transaction locked = transactionRepository.findByTransactionIdForUpdate(tx.getTransactionId()).orElseThrow();
    locked.setRiskScore(fraud.riskScore());
    locked.setDeviceFingerprint(cmd.deviceFingerprint());
    BigDecimal fee = feeEvaluationService.evaluateFee(tenantId, request.amount());
    locked.setFeeAmount(fee);
    feeEvaluationService.findRuleForTenant(tenantId)
            .ifPresent(r -> locked.setFeeRuleId(r.getId()));
    capturedFee[0] = fee;
    capturedFeeRuleId[0] = locked.getFeeRuleId();
    return null;
});
```

Then update the `PaymentResponse.accepted(...)` call (currently line 212) to pass the captured values:

```java
PaymentResponse response = PaymentResponse.accepted(
    tx.getTransactionId(), "PROCESSING", result.providerRef(),
    capturedFee[0], capturedFeeRuleId[0]);
```

The idempotency replay path (line 141) deserializes from JSON via `JsonUtil.toObject(cr.responseBody(), PaymentResponse.class)`. Existing cached entries predate fee fields — Jackson will set feeAmount to null on old entries. Add a null guard in the idempotency replay deserialization: after deserializing the cached response, if `feeAmount` is null replace with `BigDecimal.ZERO`. Do this in the replay branch in `initiate()`:

```java
PaymentResponse cached = JsonUtil.toObject(cr.responseBody(), PaymentResponse.class);
if (cached.feeAmount() == null) {
    cached = new PaymentResponse(cached.transactionId(), cached.status(), cached.providerRef(),
        cached.errorCode(), cached.errorMessage(), BigDecimal.ZERO, cached.feeRuleId());
}
return cached;
```

Do NOT change the `failed(...)` call sites — `PaymentResponse.failed` already passes `BigDecimal.ZERO` internally.
