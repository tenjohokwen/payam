**TXN-01** `initRow_existsAtProviderCallTime()`:
Register a WireMock `RequestListener` on `mtnServer` BEFORE the payment is posted. The
listener captures the DB row count when the POST `/v1_0/requesttopay` arrives:
```java
AtomicInteger rowCountAtProviderCall = new AtomicInteger(-1);
RequestListener listener = (request, response) -> {
    if (request.getUrl().contains("/v1_0/requesttopay")) {
        rowCountAtProviderCall.set(jdbcTemplate.queryForObject(
            "SELECT count(*) FROM main.transaction WHERE tx_status = 'INITIATED'",
            Integer.class));
    }
};
mtnServer.addMockServiceRequestListener(listener);
try {
    // POST payment and drive to completion
    // assert rowCountAtProviderCall.get() >= 1
} finally {
    mtnServer.removeMockServiceRequestListener(listener);
}
```
**CRITICAL**: Use try-finally to guarantee `mtnServer.removeMockServiceRequestListener(listener)`
is called even if assertions fail. This matches the `InitBeforeProviderCallTest` pattern from
plan 23-01 and prevents listener bleed across shared Spring context in subsequent test methods.
Note: `RequestListener` is `com.github.tomakehurst.wiremock.core.RequestListener`.

**TXN-02** `exceptionAfterInit_doesNotRollbackInitRow()`:
