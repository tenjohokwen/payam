**InitBeforeProviderCallTest** (INV-09-TEST):
- `initRow_existsInDb_whenProviderCallArrives()`: Register a WireMock `RequestListener`
  on `mtnServer` BEFORE the payment is posted. The listener fires when WireMock receives
  POST `/v1_0/requesttopay` and captures the DB row count into an `AtomicInteger`:
  ```java
  AtomicInteger rowCountAtProviderCall = new AtomicInteger(-1);
  RequestListener listener = (request, response) -> {
      if (request.getUrl().contains("/v1_0/requesttopay")) {
          rowCountAtProviderCall.set(jdbcTemplate.queryForObject(
              "SELECT count(*) FROM main.transaction WHERE tx_status = 'INITIATED'",
              Integer.class));
      }
  };
  mtnServer.addMockServiceRequestListener(listener);
  ```
  After posting payment and completing the flow, assert `rowCountAtProviderCall.get() >= 1`.
  In `@AfterEach` (or after assertion): `mtnServer.removeMockServiceRequestListener(listener)`.
  Note: `RequestListener` is `com.github.tomakehurst.wiremock.core.RequestListener`.

  String createtime = "2024-01-15T10:30:00";
  Instant watInstant = OrangeTimeUtil.parseOrangeTimestamp(createtime);
  Instant utcInstant = LocalDateTime.parse(createtime,
      DateTimeFormatter.ofPattern("yyyy-MM-dd'T'HH:mm:ss"))
      .toInstant(ZoneOffset.UTC);
