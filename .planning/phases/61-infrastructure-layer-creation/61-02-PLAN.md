```java

```
The `"tenantAsyncConfig"` configuration name and the `"taskExecutor"` bean name MUST NOT change.
Stripping the qualifier causes `BeanDefinitionOverrideException` against `email.config.AsyncConfig`.

From DataSourceConfig.java (current location: config/):
```java
@Configuration(proxyBeanMethods = false)
@EnableJpaAuditing
@EnableTransactionManagement

    @Bean HikariConfig hikariConfig(DataSourceProperties dataSourceProperties) { ... }
}
```

default bean name `dateTimeProvider`, which is the @Component name on `AuditingDateTimeProvider`
(now living at infrastructure.persistence after Plan 61-01).
