**Step C — Create ApiKeyService**

Package: `com.softropic.payam.tenant.service`
This service is the security-critical core. Follow these rules exactly:

1. **Key generation**: Use `SecureRandom` + `Base64.getUrlEncoder().withoutPadding()` over 32 bytes. Do NOT use UUID. Do NOT use RandomStringUtils.
2. **Key storage**: Hash with `DigestUtils.sha256Hex(rawKey)` (commons-codec, already in pom.xml). Store the hash. Never log or store the raw key.
3. **Key prefix**: Take the first 8 characters of the raw key for `keyPrefix` (used for identification, not authentication — non-secret).
4. **Authentication query**: Always compute `DigestUtils.sha256Hex(presentedKey)` first, then query with grace deadline = `Instant.now().minus(Duration.ofHours(24))`.
5. **Rotation**: Set the old key's `keyStatus = ROTATED` and `rotatedAt = Instant.now()`, then generate + persist a new ACTIVE key. Both are valid during the 24-hour grace window.
6. **Revocation**: Set `keyStatus = REVOKED` immediately. Revoked keys are excluded from the `findValidKeyByHash` JPQL query by design (query only matches ACTIVE or ROTATED-within-grace).

```java
@Service
@Transactional
public class ApiKeyService {

    private static final Duration GRACE_PERIOD = Duration.ofHours(24);

    private final TenantApiKeyRepository keyRepository;

    public ApiKeyAndRawKey generateAndStore(Tenant tenant, String environment) {
        String rawKey = generateSecureKey();
        String hash   = DigestUtils.sha256Hex(rawKey);
        String prefix = rawKey.substring(0, 8);

        TenantApiKey entity = TenantApiKey.builder()
            .tenant(tenant)
            .keyHash(hash)
            .keyPrefix(prefix)
            .keyStatus(ApiKeyStatus.ACTIVE)
            .environment(environment)
            .build();

        TenantApiKey saved = keyRepository.save(entity);
        return new ApiKeyAndRawKey(saved, rawKey);   // rawKey passed up once, then discarded
    }

    @Transactional(readOnly = true)
    public TenantApiKey authenticate(String rawKey) {
        String hash = DigestUtils.sha256Hex(rawKey);
        Instant graceDeadline = Instant.now().minus(GRACE_PERIOD);
        return keyRepository.findValidKeyByHash(hash, graceDeadline)
            .orElseThrow(() -> new AuthenticationException("Invalid or expired API key"));
    }

    public ApiKeyAndRawKey rotate(Long keyId) {
        TenantApiKey old = keyRepository.findById(keyId)
            .orElseThrow(() -> new ResourceNotFoundException("Key not found"));
        old.setKeyStatus(ApiKeyStatus.ROTATED);
        old.setRotatedAt(Instant.now());
        keyRepository.save(old);
        return generateAndStore(old.getTenant(), old.getEnvironment());
    }

    public void revoke(Long keyId) {
        TenantApiKey key = keyRepository.findById(keyId)
            .orElseThrow(() -> new ResourceNotFoundException("Key not found"));
        key.setKeyStatus(ApiKeyStatus.REVOKED);
        keyRepository.save(key);
    }

    private String generateSecureKey() {
        byte[] bytes = new byte[32];
        new SecureRandom().nextBytes(bytes);
        return Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
    }
}
```

Create a simple inner record or value type `ApiKeyAndRawKey(TenantApiKey entity, String rawKey)` to pass the raw key up to the controller without losing it.
