**ReconciliationService** (`@Service`) — orchestrates reconciliation for one provider+date pair. Constructor-injected: `LedgerSnapshotService`, `ReconciliationReportRepository`, `ReconciliationDiscrepancyRepository`, and provider adapters.

Recommended wiring: add a `MobilePaymentProvider provider()` default method to `ProviderReportPort`, implemented by each adapter returning `MTN` and `ORANGE` respectively. Then inject `List<ProviderReportPort>` and build the map in the service constructor.

Main method `runForDate(LocalDate reportDate)`:
1. For each provider in `[MTN, ORANGE]`:
   a. Create a `ReconciliationReport` entity, save with status='IN_PROGRESS'.
   b. Fetch `List<Transaction> ledgerTxs = ledgerSnapshotService.findTransactionsForDateAndProvider(reportDate, provider)`.
   c. For each `tx` in `ledgerTxs`:
      - Call `port.fetchProviderRecord(tx.getProviderRef(), reportDate)`.
      - If `record.unconfirmed()`: build discrepancy with type=UNCONFIRMED, severity=LOW.
      - Else if `record.providerStatus()` is null or indicates "not found": build MISSING_IN_PROVIDER, severity=HIGH.
      - Else compare statuses: if they differ and both are final → STATUS_MISMATCH (MEDIUM). If amounts differ (and both non-null) → AMOUNT_MISMATCH (HIGH). If both match → matched.
   d. Update report counts: `totalChecked = ledgerTxs.size()`, `totalMatched`, `totalDiscrepancies`.
   e. Save all discrepancy entities, update report status to 'COMPLETE'.
2. Log summary per provider at INFO level.

Exception handling: wrap each provider loop in try/catch so one provider failure does not abort the other.

**ReconciliationJob** (`@Component`, extends `QuartzJobBean`) — pattern exactly as `WebhookDeliveryJob`. `@Transactional` on `executeInternal()` (NOT on `execute()` which is final). Constructor-inject `ReconciliationService`. In `executeInternal()`:
```java
LocalDate yesterday = LocalDate.now(ZoneOffset.UTC).minusDays(1);
log.info("ReconciliationJob: running for date {}", yesterday);
reconciliationService.runForDate(yesterday);
```
Catch top-level exceptions and log ERROR to prevent Quartz from unscheduling the trigger.

**ReconciliationSchedulerConfig** (`@Configuration`) — uses CronScheduleBuilder for daily 02:00 UTC:
```java
@Bean
public JobDetail reconciliationJobDetail() {
    return JobBuilder.newJob(ReconciliationJob.class)
        .withIdentity("reconciliationJob")
        .storeDurably()
        .build();
}

@Bean
public Trigger reconciliationTrigger(JobDetail reconciliationJobDetail) {
    return TriggerBuilder.newTrigger()
        .forJob(reconciliationJobDetail)
        .withIdentity("reconciliationTrigger")
        .withSchedule(CronScheduleBuilder.cronSchedule("0 0 2 * * ?"))
        .build();
}
```
