```java
// TENT-07: reactivate tenant (returns new PROD key)
@PostMapping("/{tenantRef}/reactivate")
@PreAuthorize(SecurityConstants.HAS_ADMIN_ROLE)
public ApiKeyDto reactivate(@PathVariable String tenantRef) {
    ApiKeyService.ApiKeyAndRawKey result = tenantService.reactivate(tenantRef);
    return new ApiKeyDto(
        result.entity().getId(),
        result.entity().getKeyPrefix(),
        result.entity().getEnvironment(),
        result.rawKey()
    );
}

// TENT-08: regenerate webhook secret (returns 204; secret retrieved via GET)
@PostMapping("/{tenantRef}/webhook-secret")
@ResponseStatus(HttpStatus.NO_CONTENT)
@PreAuthorize(SecurityConstants.HAS_ADMIN_ROLE)
public void regenerateWebhookSecret(@PathVariable String tenantRef) {
    tenantService.regenerateWebhookSecret(tenantRef);
}
```

Note: `POST /{tenantRef}/webhook-secret` (TENT-08) returns 204 -- the new secret is retrieved separately via `GET /{tenantRef}/webhook-secret` (WSEC-03, added in Plan 01). The `regenerateWebhookSecret` return value is intentionally discarded.

**4. Add IllegalStateException handler to ApiAdvice** (research pitfall #2):

In `ApiAdvice.java`, add this handler method (place it near the `entityNotFoundExceptionHandler`):

```java
@ExceptionHandler(IllegalStateException.class)
@ResponseStatus(HttpStatus.CONFLICT)
public ErrorDto illegalStateExceptionHandler(final IllegalStateException ise) {
    final String defaultMsg = "The requested operation conflicts with current state";
    return logErrorAndReturnDTO(ise, defaultMsg, "generic.conflict");
}
```

This ensures `ApiKeyService.generateAndStore` throwing `IllegalStateException("Active key already exists for environment: PROD")` returns 409 Conflict instead of 500 Internal Server Error.
