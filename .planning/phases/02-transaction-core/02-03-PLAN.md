**V4__ledger_schema.sql** — create `main.ledger_entry` table. This table does NOT extend AbstractAuditingEntity — it only has `created_date`. No `status`, `created_by`, `last_modified_by` columns (same reasoning as `payment_event_log` — see Pitfall 3 in research):

```sql
CREATE TABLE main.ledger_entry (
    id              BIGINT PRIMARY KEY,
    transaction_id  VARCHAR(36) NOT NULL,
    entry_group_id  VARCHAR(36) NOT NULL,
    tenant_id       BIGINT NOT NULL REFERENCES main.tenant(id),
    direction       VARCHAR(6) NOT NULL CHECK (direction IN ('DEBIT', 'CREDIT')),
    account_code    VARCHAR(50) NOT NULL,
    amount          NUMERIC(20, 2) NOT NULL CHECK (amount > 0),
    currency        CHAR(3) NOT NULL,
    created_date    TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_ledger_transaction_id  ON main.ledger_entry(transaction_id);
CREATE INDEX idx_ledger_entry_group_id  ON main.ledger_entry(entry_group_id);
CREATE INDEX idx_ledger_tenant_id       ON main.ledger_entry(tenant_id);
```

**IdempotencyService.java** — `@Service`. Dependencies: `StringRedisTemplate`, `IdempotencyKeyRepository`. Constants:
- `TTL = Duration.ofHours(24)`
- `KEY_PREFIX = "idempotency:"`

Methods (see research Pattern 4 for full implementation):

`checkAndReserve(Long tenantId, String idempotencyKey) → Optional<CachedResponse>`:
- Build Redis key: `KEY_PREFIX + tenantId + ":" + idempotencyKey`
- Call `redis.opsForValue().setIfAbsent(redisKey, "RESERVED", TTL)`
- If `Boolean.FALSE` returned: key exists → get the stored value, parse as CachedResponse if not "RESERVED", return it
- If `Boolean.TRUE` (or exception): key was absent → return `Optional.empty()`
- On any Redis exception: fall back to `repo.findByTenantIdAndIdempotencyKey(tenantId, idempotencyKey)` → map to CachedResponse

`store(Long tenantId, String idempotencyKey, int httpStatus, String responseBody)`:
- Build same Redis key
- `redis.opsForValue().set(redisKey, CachedResponse.toJson(httpStatus, responseBody), TTL)` — replaces "RESERVED"
- Upsert PostgreSQL: `repo.findByTenantIdAndIdempotencyKey(...)` → update if exists, otherwise `repo.save(new IdempotencyKey(...))`
