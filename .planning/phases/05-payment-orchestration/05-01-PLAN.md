    **PaymentOrchestrator.java** — `com.softropic.payam.payment.service`
    `@Service` class. Constructor-inject: `OrangeMoneyPort orangePort`, `MtnMoMoPort mtnPort`,
    `MsisdnRouter msisdnRouter`, `TransactionService transactionService`,
    `IdempotencyService idempotencyService`, `TransactionRepository transactionRepository`,
    `EventLogService eventLogService`.

    Public method: `PaymentResponse initiate(Long tenantId, PaymentRequest request)`
    Do NOT annotate with `@Transactional` — this would hold a DB connection during outbound HTTP (Pitfall 1 / P8.1).

    Sequence (from RESEARCH.md Pattern 2):
    ```
    1. Resolve provider: MobilePaymentProvider provider = msisdnRouter.resolve(request.msisdn())
       catch UnknownMsisdnPrefixException -> return PaymentResponse.failed(null, UNKNOWN_MSISDN_PREFIX, e.getMessage())

    2. Idempotency check: Optional<CachedResponse> cached = idempotencyService.checkAndReserve(tenantId, request.idempotencyKey())
       if cached.isPresent():
         CachedResponse cr = cached.get()
         if "RESERVED".equals(cr.responseBody()): return PaymentResponse.failed(null, PAYMENT_ALREADY_PROCESSING, "Payment already in progress")
         else: return PaymentResponse from cached JSON (deserialize to PaymentResponse)

    3. Initiate transaction: Transaction tx = transactionService.initiate(tenantId, provider, request.amount(), request.currency(), request.externalReference())

    4. Build command: PaymentCommand cmd = new PaymentCommand(tx.getTransactionId(), tx.getTraceId(), tenantId, request.msisdn(), request.amount(), request.currency(), request.externalReference(), request.idempotencyKey(), provider)

    5. Select port: MobileMoneyPort port = resolvePort(provider)

    6. Dispatch (OUTSIDE any @Transactional):
       try {
         ProviderResult result = port.initiateMerchantPayment(cmd)
         // Apply state transitions (INITIATED -> AUTH_PENDING -> AUTHORIZED -> PROCESSING)
         // The state machine requires: INITIATED->AUTH_PENDING->AUTHORIZED->PROCESSING (3 steps)
         // These transitions represent: provider acknowledged -> request authorized -> async processing
         transactionTemplate.execute(status -> {
             Transaction locked = transactionRepository.findByTransactionIdForUpdate(tx.getTransactionId()).orElseThrow()
             locked.applyTransition(TransactionStatus.AUTH_PENDING)
             locked.applyTransition(TransactionStatus.AUTHORIZED)
             locked.applyTransition(TransactionStatus.PROCESSING)
             return null
         })
         PaymentResponse response = PaymentResponse.accepted(tx.getTransactionId(), "PROCESSING", result.providerRef())
         idempotencyService.store(tenantId, request.idempotencyKey(), 202, JsonUtil.toJson(response))
         return response

       } catch (CallNotPermittedException e) {
         applyFailed(tx, TransactionStatus.INITIATED, OrchestratorError.PROVIDER_UNAVAILABLE, "Circuit open")
         return PaymentResponse.failed(tx.getTransactionId(), PROVIDER_UNAVAILABLE.getErrorCode(), "Provider temporarily unavailable")

       } catch (SubscriberInactiveException | MtnAccountInactiveException e) {
         applyFailed(tx, TransactionStatus.INITIATED, OrchestratorError.SUBSCRIBER_INACTIVE, e.getMessage())
         return PaymentResponse.failed(tx.getTransactionId(), SUBSCRIBER_INACTIVE.getErrorCode(), e.getMessage())

       } catch (HttpClientException e) {
         applyFailed(tx, TransactionStatus.INITIATED, OrchestratorError.PROVIDER_ERROR, e.getMessage())
         return PaymentResponse.failed(tx.getTransactionId(), PROVIDER_ERROR.getErrorCode(), "Provider error: " + e.getHttpStatusCode())

       } catch (Exception e) {
         applyFailed(tx, TransactionStatus.INITIATED, OrchestratorError.PROVIDER_ERROR, e.getMessage())
         return PaymentResponse.failed(tx.getTransactionId(), PROVIDER_ERROR.getErrorCode(), "Internal error")
       }
    ```

    Private helpers:
    - `resolvePort(MobilePaymentProvider provider)` — switch on ORANGE/MTN/NEXTTEL (throw UnsupportedOperationException for NEXTTEL)
    - `applyFailed(Transaction tx, TransactionStatus from, OrchestratorError error, String metadata)` — uses TransactionTemplate to call `tx.applyTransition(FAILED)` + `eventLogService.append(PROVIDER_FAILED, from, FAILED, "ORCHESTRATOR", error.name())`

    CRITICAL NOTES:
    - Use `org.springframework.transaction.support.TransactionTemplate` (inject it) for the state transition block — this creates a new transaction scope without annotating the orchestrator method
    - Catch `CallNotPermittedException` BEFORE `HttpClientException` BEFORE generic `Exception` — ordering matters (Pitfall 4)
    - Catch `com.softropic.payam.common.client.exception.HttpClientException`, NOT `org.springframework.web.client.HttpClientErrorException` — RestRequestInterceptor converts all 4xx/5xx before Spring's error handler (Pitfall 2)
    - The state machine path is INITIATED → AUTH_PENDING → AUTHORIZED → PROCESSING (three `applyTransition` calls in sequence) — a single `applyTransition(PROCESSING)` from INITIATED will throw IllegalStateTransitionException
    - Use `com.softropic.payam.common.util.JsonUtil` for JSON serialization of idempotency response body; check its API before using
    - CachedResponse: check `com.softropic.payam.transaction.contract.CachedResponse` for how to deserialize the cached JSON back to PaymentResponse

    **PaymentResource.java** — `com.softropic.payam.payment.api`
    `@RestController` class. Constructor-inject: `PaymentOrchestrator orchestrator`.

    ```java
    @PostMapping("/v1/payments")
    public ResponseEntity<PaymentResponse> initiatePayment(
            @RequestBody @Valid PaymentRequest request,
            @AuthenticationPrincipal TenantPrincipal principal) {
        PaymentResponse response = orchestrator.initiate(principal.getTenantId(), request);
        if (response.errorCode() != null) {
            // Error responses use 422 for domain errors, 503 for circuit open
            HttpStatus status = OrchestratorError.PROVIDER_UNAVAILABLE.getErrorCode().equals(response.errorCode())
                ? HttpStatus.SERVICE_UNAVAILABLE
                : HttpStatus.UNPROCESSABLE_ENTITY;
            return ResponseEntity.status(status).body(response);
        }
        return ResponseEntity.accepted().body(response);   // 202 Accepted
    }
    ```

    - PROVIDER_ERROR → 502
    - UNKNOWN_MSISDN_PREFIX → 422
    - PAYMENT_ALREADY_PROCESSING → 202 (cached in-flight response — treat as accepted)
    - null errorCode → 202
