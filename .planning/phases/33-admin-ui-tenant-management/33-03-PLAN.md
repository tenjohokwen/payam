Create `src/frontend/src/pages/admin/TenantListPage.vue` following the `TransactionSearchPage.vue` pattern exactly.

**Template structure:**
1. `<q-page padding>` wrapper
2. Page heading: `<div class="text-h5 q-mb-md">Tenants</div>`
3. Filter card: `<q-card class="q-mb-md"><q-card-section>` containing:
   - `q-select` for status filter, options: `[{ label: 'All', value: 'ALL' }, { label: 'Active', value: 'ACTIVE' }, { label: 'Suspended', value: 'SUSPENDED' }]`, `v-model="statusFilter"`, `outlined dense`, `emit-value map-options`, `style="min-width: 200px"` inline
   - `q-btn color="primary" label="Search" @click="onSearch"` — triggers reload from page 1
4. `q-table` with these exact attributes:
   - `:rows="rows"` `:columns="columns"` `row-key="tenantRef"`
   - `:loading="loading"` `flat bordered`
   - `:pagination="pagination"` `@request="onRequest"`
   - `@row-click="onRowClick"`
5. Status column uses a custom body cell slot:
   ```vue
   <template #body-cell-tenantStatus="props">
     <q-td :props="props">
       <q-chip
         :color="props.row.tenantStatus === 'ACTIVE' ? 'positive' : props.row.tenantStatus === 'SUSPENDED' ? 'negative' : 'grey'"
         text-color="white"
         dense
       >
         {{ props.row.tenantStatus }}
       </q-chip>
     </q-td>
   </template>
   ```
6. createdAt column uses a body cell slot to format the ISO instant as a readable date string:
   ```vue
   <template #body-cell-createdAt="props">
     <q-td :props="props">
       {{ props.row.createdAt ? new Date(props.row.createdAt).toLocaleDateString() : '' }}
     </q-td>
   </template>
   ```
7. Empty state: use q-table `no-data` slot with text from UI-SPEC: heading "No tenants found", body "No tenants match your current filter. Try changing the status filter or add a tenant via the API."

**Script setup:**
- Imports: `ref` from `vue`, `useRouter` from `vue-router`, `useQuasar` from `quasar`, `adminApi` from `src/api/admin.api`
- `const $q = useQuasar()`, `const router = useRouter()`
- `const statusFilter = ref('ALL')`
- `const loading = ref(false)`, `const rows = ref([])`
- `const pagination = ref({ page: 1, rowsPerPage: 20, rowsNumber: 0 })`
- Columns definition array:
  ```javascript
  const columns = [
    { name: 'name', label: 'Tenant Name', field: 'name', align: 'left', sortable: false },
    { name: 'tenantRef', label: 'Ref', field: 'tenantRef', align: 'left', sortable: false },
    { name: 'email', label: 'Email', field: 'email', align: 'left', sortable: false },
    { name: 'tenantStatus', label: 'Status', field: 'tenantStatus', align: 'center', sortable: false },
    { name: 'createdAt', label: 'Created', field: 'createdAt', align: 'left', sortable: false },
  ]
  ```
- `onRequest` function: receives `{ pagination: p }`, sets `loading.value = true`, calls `adminApi.listTenants({ status: statusFilter.value === 'ALL' ? undefined : statusFilter.value, page: p.page - 1, size: p.rowsPerPage })`. CRITICAL: `p.page - 1` because Spring is 0-indexed, Quasar is 1-indexed. On success: `rows.value = resp.data.content`, `pagination.value = { ...p, rowsNumber: resp.data.totalElements }`. On error: `$q.notify({ type: 'negative', message: 'Failed to load tenants' })`. Finally: `loading.value = false`.
- `onSearch` function: calls `onRequest({ pagination: { ...pagination.value, page: 1 } })` to reset to page 1.
- `onRowClick` function: `function onRowClick(evt, row) { router.push('/admin/tenants/' + row.tenantRef) }` — note the `(evt, row)` signature per Quasar q-table convention (first arg is MouseEvent, not row).
- `onMounted`: call `onRequest({ pagination: pagination.value })` to load initial data.

Import `onMounted` from `vue`.
