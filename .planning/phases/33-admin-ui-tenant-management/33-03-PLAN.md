<interfaces>
adminApi.getTenantDetail(tenantRef) returns { data: TenantDetailDto }
adminApi.updateTenantName(tenantRef, { name }) returns 204
adminApi.updateTenantEmail(tenantRef, { email }) returns 204
adminApi.updateTenantWebhookUrl(tenantRef, { webhookUrl }) returns 204
adminApi.suspendTenant(tenantRef) returns 204
adminApi.reactivateTenant(tenantRef) returns { data: ApiKeyDto { id, keyPrefix, environment, rawKey } }
adminApi.regenerateWebhookSecret(tenantRef) returns 204
adminApi.getWebhookSecret(tenantRef) returns { data: { webhookSecret: string } }
adminApi.rotateKey(tenantId, keyId) returns { data: ApiKeyDto { id, keyPrefix, environment, rawKey } }
adminApi.revokeKey(tenantId, keyId) returns 204
adminApi.reactivateKey(tenantId, keyId) returns 204 (NO rawKey returned)

TenantDetailDto: { id (Long), tenantRef (String), name (String), email (String), webhookUrl (String), tenantStatus (String), keys: ApiKeySummaryDto[] }
ApiKeySummaryDto: { id (Long), keyPrefix (String), environment (String), keyStatus (String) }
  Note: NO createdDate field — omit Created Date column from key table
ApiKeyDto: { id (Long), keyPrefix (String), environment (String), rawKey (String) }

TenantStatus: 'ACTIVE' | 'SUSPENDED'
ApiKeyStatus: 'ACTIVE' | 'ROTATED' | 'REVOKED'
ApiKeyEnvironment: 'PROD' | 'DEV' | 'SANDBOX'

CRITICAL distinctions:
- Tenant-level reactivate (POST /{tenantRef}/reactivate) returns ApiKeyDto with rawKey and opens OneTimeKeyModal
- Key-level reactivate (POST /{tenantId}/keys/{keyId}/reactivate) returns 204, NO rawKey and does NOT open modal
- Key-level rotate (POST /{tenantId}/keys/{keyId}/rotate) returns ApiKeyDto with rawKey and opens OneTimeKeyModal
- Key-level revoke (DELETE /{tenantId}/keys/{keyId}) returns 204 and no modal, just notify success
- Key management endpoints use tenantId (Long from tenant.id), NOT tenantRef

OneTimeKeyModal props: rawKey (String, required), modelValue (Boolean)
OneTimeKeyModal events: update:modelValue, close
</interfaces>

**LOAD TENANT ON MOUNT:**
```javascript
async function loadTenant() {
  isLoading.value = true
  try {
    const resp = await adminApi.getTenantDetail(tenantRef)
    tenant.value = resp.data
    form.name = resp.data.name
    form.email = resp.data.email
    form.webhookUrl = resp.data.webhookUrl
  } catch {
    $q.notify({ type: 'negative', message: 'Failed to load tenant details. Please refresh the page.' })

    isLoading.value = false
  }
}
```

**PER-FIELD SAVE FUNCTIONS (D-01, D-02):**
Three separate async functions — saveName, saveEmail, saveWebhookUrl — each:
1. Sets `saving[field] = true`
2. Calls the matching adminApi method: `adminApi.updateTenantName(tenantRef, { name: form.name })` / `adminApi.updateTenantEmail(tenantRef, { email: form.email })` / `adminApi.updateTenantWebhookUrl(tenantRef, { webhookUrl: form.webhookUrl })`

5. In finally: sets `saving[field] = false`

Exact toast messages per Copywriting Contract: "Name updated successfully", "Email updated successfully", "Webhook URL updated successfully", "Failed to update name. Please try again.", "Failed to update email. Please try again.", "Failed to update webhook URL. Please try again."

```javascript
function confirmSuspend() {

}
```

confirmReactivate function:
```javascript
function confirmReactivate() {
  $q.dialog({
    title: `Reactivate ${tenant.value.name}?`,

    ok: { label: 'Reactivate', color: 'primary' },
```

**WEBHOOK SECRET REVEAL (D-13, D-14, D-15):**
```javascript
function clearTimers() {
  clearTimeout(maskTimer)
  clearInterval(countdownInterval)
  maskTimer = null
  countdownInterval = null
}

function reMask() {
  clearTimers()
  secret.value = null
  unmasked.value = false
  countdown.value = 0
}

function startAutoMask() {
  countdown.value = 30
  countdownInterval = setInterval(() => { countdown.value-- }, 1000)
  maskTimer = setTimeout(() => { reMask() }, 30000)
}

async function toggleSecret() {
  if (unmasked.value) {
    reMask()
    return
  }
  try {
    const resp = await adminApi.getWebhookSecret(tenantRef)
    secret.value = resp.data.webhookSecret
    unmasked.value = true
    startAutoMask()
  } catch {
    $q.notify({ type: 'negative', message: 'Failed to load webhook secret. Please try again.' })
  }
}

async function doRegenerateSecret() {
  regenerating.value = true
  try {
    await adminApi.regenerateWebhookSecret(tenantRef)
    reMask()
    $q.notify({ type: 'positive', message: 'Webhook secret regenerated' })
  } catch {
    $q.notify({ type: 'negative', message: 'Failed to regenerate webhook secret. Please try again.' })
  } finally {
    regenerating.value = false
  }
}

// Pitfall 3: Clean up timers on unmount to prevent memory leaks
onUnmounted(() => { clearTimers() })
```
