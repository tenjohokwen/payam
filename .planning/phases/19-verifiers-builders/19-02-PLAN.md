    ```java
    public class DeterministicUuidFactory {
        private final long seed;
        private long counter = 0;
        public DeterministicUuidFactory(long seed) { this.seed = seed; }
        public UUID next() { return new UUID(seed, counter++); }
        public void reset() { counter = 0; }
    }
    ```
    Each test class declares: `private final DeterministicUuidFactory uuids = new DeterministicUuidFactory(19_01L);` — the seed is a long literal unique per test class. counter is NOT static.

    **FraudSignalBuilder (BUILD-06)**
    Produces a map of fraud context values for passing to payment initiation. Also supports Redis velocity counter pre-seeding.

    Fields with defaults:
    - `sourceIp = "192.168.1.1"`
    - `deviceFingerprint = "test-device-fp-001"`
    - `velocityResets = new ArrayList<>()` — list of `{signalName, identifier}` pairs to delete from Redis

    Fluent: `withSourceIp(String)`, `withDeviceFingerprint(String)`
    `withVelocityCounterReset(String signalName, String identifier)` — adds to velocityResets list

    `resetVelocityCounters(StringRedisTemplate redis)` — for each entry in velocityResets, calls `redis.delete("fraud:velocity:" + signalName + ":" + identifier)`. This forces Bucket4j to create a fresh bucket at the configured limit on next check. Call this method in test `@BeforeEach` after `redis.flushDb()` (though flushDb already clears all Redis keys including velocity buckets — this method is a targeted reset for post-flushDb re-seeding of specific counters).

    `build()` — returns a `Map<String, String>` with `sourceIp` and `deviceFingerprint` keys, or whatever the production `PaymentInitiateRequest` / fraud context field structure requires. Read `PaymentInitiateRequest` and `FraudEvaluationService` to understand how IP and fingerprint are passed into fraud evaluation before deciding the return type. If `PaymentInitiateRequest` includes `deviceFingerprint` directly, then `build()` returns a configured `PaymentRequestBuilder` instead of a Map. Prefer whatever matches the production API.
